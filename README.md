# carousel-bot

Remotion-based carousel and reels pipeline for DockPlus AI.

## What is here

- Remotion templates for branded vertical videos
- Telegram polling bot that collects content inputs and renders locally
- Supabase schema and smoke test
- Brand presets and pipeline docs

## Main commands

```bash
npm run typecheck
npm run test:supabase
npm run bot:telegram
npx remotion studio remotion-templates/index.ts
```

On Windows PowerShell in this environment, use `npm.cmd` and `npx.cmd`.
